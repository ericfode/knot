# Checked structural terms and independent evaluation

Knot now checks constructor arguments and flat field patterns, preserves stable
binding identities through refinement, and evaluates structural values in Bend.
A matched parent is reconstructed from its fields; its reuse spends those field
obligations. Erased fields remain checked metadata and consume no evaluator slot.

This is a step within milestone 1. The evaluator uses persistent model trees.
Owned allocation, transfer/drop, reclamation, sound recursion and Wasm field
lowering remain pending. The emitter rejects fielded books after checking their
bodies. Existing enum Wasm programs still execute unchanged.
