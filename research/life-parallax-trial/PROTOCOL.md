# One Parallax trajectory

This is one new, prospectively evaluated trajectory using the user-selected
Parallax stimulus. It consumes **one of the remaining fifteen trajectory slots**.
The author is a fresh standalone GPT-6 Astra process at **low** reasoning, using
the existing isolated R2 transport. At most three rounds are permitted, with at
most one compiler-diagnostic-only repair per round. No candidate is authored in
the controller's conversation. Stop at the first experimental FULLPASS.

## Frozen inputs and isolation

`inputs/` preserves the supplied envelope, exact 3,912-byte decoded payload,
upstream manifest and provenance. The payload SHA-256 is
`e54aa04b8fe3f8c2a8fed4836798b49cd4f00c352b58ca4c422298346826b837`.
The packet starts with those exact bytes, then contains AUTHOR.md, the exact
experimental policy, the pinned R2 Bend guide and Base snapshot, and JSON schema.
No prior candidate, outcome, alternate stimulus, or calibration example is in
the packet. Subsequent requests reconstruct only this same packet plus that
trajectory's own responses and feedback. Compiler repair sees the preceding
response and its complete compiler diagnostic, without new review feedback.

`freeze` writes the packet and a new input lock, without modifying the supplied
inputs. The lock hashes every runner/packet input, the unchanged behavior gate,
compiler tree, fixtures, semantic wrapper/rules and installed npm dependency
files, parser and reviewer, and the exact new policy. It records runtime binary
paths, hashes and versions. The old R2 default lock and driver are never used.
Every external action is preceded and followed by this lock check. Runtime
identity is also checked before launch. No dependency installation or shared
configuration mutation is performed.

The transport uses an empty temporary directory, ignores user configuration and
rules, disables tools, plugins, memories and web, and starts fresh per request.
Raw events, prompt, schema, response, stderr, command, identity and token usage
are retained. Requested model/effort and provider-observed evidence stay distinct;
absent observations are not invented. Credentials never enter saved prompts.

## Gates and feedback

The fixed deterministic domain is binary row-major rectangular boards with both
dimensions 0..32, synchronous B3/S23 and dead exterior. Public `step` and `evolve`
preserve full-board observables, zero-turn identity and exact composition. The
unchanged independent sparse oracle and dense crosscheck are retained. Each
passing Node and Bun run has **1,537 fixtures plus 21 composition checks**; native
CPU has **28 fixtures**. The corpus exercises 0..8 turns, not every valid board
or every Nat. There is no general behavioral proof or performance claim.

First source, optional repair and final submitted source are separately frozen.
The first compiler check includes a fixed public-interface wrapper. Syntax,
types, quantities and termination precede behavior and paid reviews. A timeout
or unavailable compiler is not a diagnostic repair opportunity. Behavior uses
the R2 gate only with this explicit new lock and a globally distinct trial ID.
Large raw observations remain exact compressed receipts. Author feedback has
statuses and counts, not oracle source, fixtures or expected-output answers.

Before paid review, an offline reviewer preflight verifies source identity,
parser coverage, no labels, maximum 49,152 UTF-8 bytes and 64 declarations. The
four unchanged semantic rules are `bend-machine-arithmetic`,
`bend-fuel-completeness`, `perf-growing-prefix-copy`, and
`perf-linked-list-indexing`. The npm wrapper uses two workers, a fixed neutral
`.local/life-parallax-trial/P001/life.bend` path, full current context and exact
model `jev-1.13.0`. No incremental reroll is requested. Missing/truncated context
or zero coverage is not clean. Findings remain unresolved attention until
evidence establishes their status; the runner does not hand-repair code or
silently dismiss findings. A semantic-attention result can still receive its
single family/support review, with `semantic_clean:false` retained.

The additive reviewer receives the source and policy alone, with no condition
labels, competing results or calibration evidence in its model prompt. It uses
two workers and the exact model. Whole-program Galaxy-brain level 5 mass must be
at least .60; delight, memetic identity, anticipation and payoff each require
level >=3 mass at least .60. **Every** parsed declaration separately requires
`supports_main_idea` level >=3 mass at least .60. No averaging, rank, criticality
exemption or lower family threshold substitutes for a requirement. Complete,
untruncated, source-matching coverage and all fixed gates are mandatory.

## Limits, receipts and stopping

The policy hash remains
`2455ea1a27e80142f32f9cf0ca43af67ed905234e125811ecc06ff229d67d710`.
[Calibration](../life-helper-review/calibration/results.json) is mixed:
development separated clean `head0` (.95) from obscured `head0` (.48) and useless
relays (.04–.05), but held-out clean `eight_winds` (.94), scrambled `eight_winds`
(.81), and gratuitous `route` (.78) all passed. Thus the policy is **provisional**,
not qualified for global automatic acceptance. No control was tuned or rerolled.
An experimental FULLPASS does not validate the policy, establish an inducer
effect, or mean the unchanged global Perch v3 declaration policy passed. That
global style policy is not evaluated here. One trajectory provides no causal
comparison.

The reusable reviewer retains its historical “post-hoc” limitation string. In
this experiment the author trajectory is new, and the new policy is in the
prospective packet; this protocol records that distinction explicitly.

No unchanged source is submitted for new review. Provider/auth/credit/unfinished
review failures stop all further dispatch without retries. Model, lock or
receipt identity mismatches stop as configuration failures. All original and
repaired attempts remain. A completed terminal result can be read again only
after its saved artifact hashes match. An interrupted partial trajectory is
blocked for inspection; the runner does not automatically resume or reroll it.

`trial/round-NN/round.json` links source, compiler, behavior, semantic and style
receipts. `trial/result.json` reports all rounds and selects only a full pass as
accepted; otherwise the last source is a nonaccepted artifact. Separate token
totals and provider-request counts are retained, while unavailable monetary
cost stays null. The root operator owns final law review, interpretation and
Git checkpoints. No paid call is part of runner preparation or offline tests.
