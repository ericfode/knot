No declaration meets all three targets. This is **style attention**, not a pass.
The guard/transition/restore structure makes ownership transport explicit, but
the Bool dispatch and record reconstruction add reading overhead. A later
bounded candidate can test whether one transaction algebra removes that
repetition while retaining visible error precedence and both rejected owners.
Adding names or decorative notation to the small projection/proof functions
would not itself improve them. Existing proof forms and literal observations
stay fixed; ratings are advisory and no rewrite is justified by scores alone.

Context is bounded to explicit local helpers and callers. The receipts retain
each source/context hash, model distributions, unresolved Base references and
any truncation. This is not whole-program review, a universal proof, evidence of
physical memory reclamation, or validation of a device backend.
