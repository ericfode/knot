# Declaration contributions and complete reader units

This is an advisory policy comparison, not a production rubric change or a new
code campaign. Base: `af3b202`, rubric v6. Accepted runtime, laws, proofs, tests,
release evidence and historical ratings remain unchanged.

Hypothesis recorded before scoring: a declaration can contribute a recognizable
idiom without independently carrying the mechanism's expressive hook. Algorithmic
centrality and public visibility do not establish a standalone hook obligation.

The draft uses Compression/Delight level 3 and Memetic/Anticipation/Payoff level 2
for every declaration inside a preselected complete reader unit. The complete
unit retains level 3 for the expressive axes. All probability thresholds remain
0.60. A one-function unit still receives the stronger composition judgment.
Visibility is context; renaming or hiding a function cannot remove its unit's
obligation. Existing Galaxy relevance and deterministic acceptance are unchanged.

V6's original axis definitions remain intact. Draft declaration prompts append
only an instruction to assess the selected declaration's contribution. Memetic
appeal remains independent of conceptual value: recognizable decoration may earn
memetic credit while failing Compression, Delight or another axis. Composition
requests are identical between policies and are reused by exact request hash.

Four fixed source groups receive both policies, at most eight file-group checks:

1. Exposed IntMap endpoint/locality laws, both thin specializations and projection
   lemmas, using the already compiler-checked mechanical review copy. The known
   imported-template observer defect is not repaired or counted as coverage here.
2. Current IntMap API operations, internal recurrence and projection helpers,
   with its complete source and fixed SPEC/INTERFACE.
3. A fresh complete polynomial-fingerprint mechanism with an internal recurrence
   and a thin public wrapper, with independent literal runtime observations.
4. A fresh behavior-equivalent mechanism with unnecessary internal indirection.
   Its internal status must not exempt it from Compression/Delight judgments.

The draft is frozen before the two fresh source groups are authored. All sources,
scope manifests, expectations and request identities are frozen before any paid
review. The fresh groups are reserved controls, not user-labelled taste gold.
Expectations are assistant hypotheses: comparable specializations should have
the same declaration obligation; clear internal/public contributions should not
need independent quotability; needless indirection should still fail at least
one clarity/compression target. Negative or uncertain outcomes remain visible.

The provider receives source, the fixed task, selected symbol and complete unit
membership. It receives no expectations, old scores, keep/reject labels or policy
version. Run once per distinct request with Jev 1.13.0, concurrency 2. No provider
retry, source tuning or post-result rubric tuning. Stop on provider failure.

Also compute a clearly labelled arithmetic sensitivity view of existing v6
IntMap distributions at level 2. It is not a fresh rating or a retroactive pass.
Retain old role uncertainty, context limitations and all failed composition bars.
Run the existing v6 vacuity-control verifier unchanged; do not rerate it.

Unknown scope/context produces unavailable draft qualification. The old role
posterior remains diagnostic and is never silently relabelled as supporting.
Even a complete supplemental packet cannot establish canonical parser coverage.
No result in this experimental harness automatically promotes the production
policy or authorizes rewriting accepted source.

Closeout includes exact source/policy/request identities, full distributions,
deterministic controls, exposed/held-out distinctions, whether the intended
separation occurred, limitations, and a concrete adoption recommendation. Keep
the broader campaign parked.
