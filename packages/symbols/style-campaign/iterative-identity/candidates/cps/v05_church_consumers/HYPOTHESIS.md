Use Church ownership throughout instead of keeping a constructor-shaped wrapper. Each response handler returns the consumer for the untouched store. A vector read therefore becomes `t(R, v => metadata(read(v)))`; closing ownership is uniformly `R => k => k(v,m)`. This tries to remove named reassembly and make the two-store handoff visible in the type and expression together. The original probe-before-append and append-before-publication order remains.
