# IntMap collision-observation controls

The package rule checks two semantic hazards: reversed combiner arguments and
combining one-sided entries. Shared law rules cover broader adequacy. These
bounded controls calibrate only the collision observation; the rule is advisory.

Initial publication had no provider credentials; receipts/perch.json preserves
that historical result. The [live audit](../../PERCH_REPORT.md) used jev-1.13.0:
clean 0.12 broken probability, broken 0.93, held-out clean 0.08, and fresh
held-out equal-values broken 0.89. Both negative cases were detected at the
unchanged 0.80 floor. The original three cases contain expected-label hints;
the fresh equal-values case does not. This is not a production accuracy estimate.

Receipts are under the package's receipts/perch-audit-2026-09-26 directory.
