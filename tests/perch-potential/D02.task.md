# Queries over labelled paths

Inputs are finite directed multigraphs with named vertices and edges. Each edge
has a label from a finite alphabet and a nonnegative integer cost. A query gives
start and finish vertices and a finite expression built from labels, alternatives,
concatenation and repetition. Empty paths are allowed exactly where the expression
allows the empty word. Parallel edges remain distinct path choices.

For the same query, provide whether a matching path exists, the minimum total
cost of a matching path when one exists, and the number of matching paths of
each length. The last result must support an exact finite coefficient request
for any supplied length, even when cycles yield infinitely many paths overall.
Each distinct edge sequence counts once, regardless of how many expression
derivations recognize its label sequence.

Also retain the path contribution expression: alternatives denote disjoint path
choices and concatenation joins compatible paths. Interpreting this expression
as existence, cost or length counts must agree with the corresponding observable.
A finite cyclic representation of these contributions is allowed.
The result must be unchanged by vertex renaming, expression reassociation, or
eliminating internal graph vertices in different orders. A labelled subgraph may
be replaced by its computed boundary-to-boundary summaries without changing any
query whose endpoints are outside its interior. Explain why these replacement
and interpretation requirements hold for cyclic as well as acyclic inputs.
