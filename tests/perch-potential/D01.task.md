# Four-character hexadecimal conversion

Provide two pure operations between unsigned 16-bit integers and text.

Formatting accepts every integer from 0 through 65,535 and returns exactly four
ASCII characters. Characters are lowercase hexadecimal digits, with leading
zeroes retained. Their left-to-right place values are 4,096, 256, 16 and 1.

Parsing accepts a finite text value. It succeeds exactly when the text has four
characters and every character belongs to 0–9 or a–f. Success returns the integer
represented by those place values. All other text returns one invalid-input
result. Uppercase letters, signs, spaces, separators, prefixes and Unicode
lookalikes are rejected. The parser does not trim or normalize its input.

Parsing a formatted integer must recover that integer. Formatting a successfully
parsed text must reproduce that text exactly. Both operations leave their inputs
unchanged and produce the same result on every call. There is no locale,
streaming state, configurable base, alternative encoding, network format or
additional diagnostic requirement. Internal arithmetic must preserve the stated
range and reject invalid text without overflow or partial success.
