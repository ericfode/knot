# Validate imported shipment rows

Input is an ordered finite list of records with exactly these fields: reference
text, destination text, service text, package count integer and mass-in-grams
integer. Check each record independently and return the records in their
original order, paired with all applicable error codes.

A reference must contain between one and twenty ASCII letters or digits. A
destination must consist of exactly two uppercase ASCII letters. Service must
be ground or air. Package count must be between one and one hundred inclusive.
Mass must be between one and fifty thousand inclusive. An air shipment may not
exceed twenty thousand grams; apply that additional check only when service and
mass have individually valid values. For an invalid field, emit its field name
as the code; emit air-mass-limit for the additional check. Order codes by the
field order above, followed by air-mass-limit. A valid record has an empty code
list. Do not stop after the first error or change any field value.

Empty input returns empty output. Duplicate references are permitted and do not
affect validation. No address lookup, shipping price, routing, packing, unit
conversion, persistence, cross-record rule or additional field is required.
