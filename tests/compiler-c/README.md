# Native C conformance gate

`BEND_NO_TELEMETRY=1 python3 tests/compiler-c/check.py` builds the C compiler,
fielded Wasm compiler, checker and evaluator from the pinned seed in native and
Bun lanes. The immutable `receipts/reference.json` freezes 46 source programs,
143 calls and all 19 original recursion observations. `cases.json` points to
unchanged suite files and the 13 new fixtures; it does not copy or amend the
existing suites' assertions.

| Corpus | Programs | Calls |
| --- | ---: | ---: |
| Existing enum Wasm corpus | 25 | 90 |
| Existing fielded Wasm corpus | 8 | 32 |
| Original recursion sources with appended exact-tree observers | 11 | 11 |
| Simultaneous tail parameter rebind | 1 | 9 |
| Non-tail recursive copy | 1 | 1 |

For each call the gate runs the seed, independent evaluator, Node Wasm and
native C. It compares the emitted C bytes across compiler lanes, compiles with
`cc -O2 -std=c99 -Wall -Werror -fwrapv`, and reruns every call with
`-fsanitize=address,undefined`. Receipts include the exact `cc --version` output,
source and output hashes, commands, classifications and observations.

The fielded corpus has two intentionally distinct observations. Its
`arena-overflow` entry succeeds in the seed and evaluator but exhausts the
bounded Wasm and C arenas. Its `deep-call` entry exceeds the evaluator CLI's
fixed parser budget; the compile entries use the corpus's larger explicit
parser/checker budgets. These are recorded as Exhausted, not relabeled as
successful four-way equality.

All 11 original accepted recursion files also compile directly as C in both
lanes, including books with no enum-signatured exports. All 19 original
recursion checker/evaluator assertions remain exact. The 32 original enum-suite
checker rejections and eight recursion rejections preserve their classes and
leave existing output artifacts unchanged in both backends and lanes.

The bounded arena probes retain the field suite's exact slot boundaries:
`f0` succeeds 8,192 times, erased-only and nullary cells 16,384 times, and
three-slot pairs 5,461 times; the next call reports exit 4. A non-tail 64-node
copy exhausts a depth-32 build. A 64-step tail recursion completes at depth 8.
Budget failures preserve stale output; malformed, wrongly typed and structured
host arguments remain HostFailure.

The gate kills four type-correct semantic mutants: swapped live-field offsets,
a missing arena bound check, an inverted tag comparison, and a tail jump that
skips rebinding an accumulator. The missing-bound witness never dereferences
its one-past pointer. See [LAW_REVIEW.md](LAW_REVIEW.md) for the eight checked
laws, independent controls and proof limits, and [SPEC.md](SPEC.md) for the ABI.

`receipts/c.json` is the current execution record; it is written only by a full
gate attempt and records `incomplete` on failure. `receipts/reference.json` is
immutable and is never regenerated by the normal gate. Build products remain
under ignored `.local/compiler-c/gate/`. The default compiler CLIs are unchanged.

The host adapter has four separately fixed controls in
`host-expectations.json`: successful invocation, unknown export, missing C
artifact and malformed C. The gate hashes and invokes `scripts/run-c.py` for
these probes. ASan and UBSan remain enabled; unsupported Darwin leak detection
is disabled. `receipts/attempts.json` retains the earlier host-option and mutant
compiler failures, neither of which counts as a semantic kill.

The bounded independent [review packet](receipts/review.json) adds three probes
outside the registered counts: 256-tag match, nested 256-tag match, and a
300-node non-tail recursion that exhausts the default depth guard under
sanitizers.

Offline rubric-v8 preflight covers **269 declarations in 17 files**. It reports
50 truncated declarations and 65 declarations whose supporting role cannot be
established; the combined context is unavailable because of unresolved context
and the composition byte limit. The separate `c-backend` manifest family covers
107 declarations in four files, with 23 truncated declarations, 47 supporting
roles unresolved, and no available composition. Both receipts make zero
provider requests. These are structural blockers, not semantic or style ratings;
live qualification belongs to the coordinator.

## Recorded direct gate result

The final direct gate passed with Apple clang 21.0.0
(`clang-2100.1.1.101`), target `arm64-apple-darwin25.5.0`. All counts below are
observations against fixed expectations; categories overlap.

| Check | Exact passing coverage |
| --- | ---: |
| Corpus | 46 programs, 143 seed calls |
| Original recursion reference | 19 observations |
| Independent evaluator, native and Bun | 286 observations: 284 results, 2 expected parser-budget exhaustions |
| Node Wasm, native and Bun compiler output | 286 observations: 284 results, 2 expected arena exhaustions |
| Native C, native and Bun compiler output | 286 observations: 284 results, 2 expected arena exhaustions |
| ASan and UBSan | 143 observations: 142 results, 1 expected arena exhaustion; no sanitizer findings |
| C byte identity | 57 pairs: 46 corpus books and 11 original recursion books |
| Wasm byte identity | 46 pairs |
| Original recursion checker and evaluator | 76 phase observations |
| Original recursion C compilation | 22 builds |
| Rejections | 80 lane cases, each checked through C, Wasm and evaluator: 240 observations |
| Resource and compiler-budget boundaries | 17 probes |
| Host boundaries | 18 probes, including 4 host-adapter probes |
| Semantic mutants | 4 of 4 killed in both compiler lanes |
| Complete C proof entry | 8 of 8 laws checked |

The receipt is [c.json](receipts/c.json). Existing gates' receipts were not
changed by this gate. The campaign's complete scratch-run result is a separate
integration check. The [executor report](REPORT.md) records all fifteen gates,
the first benchmark, review limits and the coordinator's next steps.
